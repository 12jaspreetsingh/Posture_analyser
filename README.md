# Smart Posture Detection System 📷

A simple computer vision project that checks your sitting posture using your webcam.
It gives a posture score and alerts you when your posture is not correct.

---

## 🚀 Features

* Real-time posture detection using webcam
* Detects neck tilt, spine position, and shoulder alignment
* Gives a posture score (0–100)
* Shows alerts for bad posture
* Displays a clean UI with live feedback
* Option to take screenshots

---

## 🛠️ Technologies Used

* Python
* OpenCV
* MediaPipe
* NumPy

---

## ▶️ How to Run

1. Install required libraries:

```
pip install opencv-python mediapipe numpy
```

2. Run the program:

```
python posture_detection.py
```

---

## 🎮 Controls

* **S** → Toggle skeleton view
* **H** → Toggle HUD (display)
* **P** → Take screenshot
* **Q** → Quit

---

## 📸 Output

* Live camera feed with posture analysis
* Score and alerts shown on screen
